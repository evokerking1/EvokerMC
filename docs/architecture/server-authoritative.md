# Server-Authoritative Architecture

EvokerMC uses a **server-authoritative architecture** where the server is the single source of truth for all game state.

## Benefits

1. **Fair Multiplayer**: Server validates everything
2. **Consistent State**: Single source of truth
3. **Easier Development**: Same code for singleplayer/multiplayer
4. **Mod Safety**: Mods run on server
